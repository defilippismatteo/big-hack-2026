# ADERA — remix indipendente

## Stato
Bloccato prima della costruzione dal gate di accesso di HyperFrames Reverse.
Nessun progetto animato o MP4 prodotto. Nessuna API generativa, chiamata Google,
spesa, billing o render cloud eseguiti. Nessun server lasciato attivo.

Modello richiesto: gpt-6.1-sol; provider: OpenAI via Codex/T3 Code;
reasoningEffort richiesto: low.

Sono stati letti reverse-any-video, hyperframes e i tre documenti del brief,
incluso ASSET_STATO_2026-11-15.md prevalente. Il remix resta autorizzato come
interpretazione ADERA, senza voce e sottotitoli, non copia pixel-identica.

## Ripresa
Eseguire interattivamente `npx hyperframes auth login` e completare l'accesso.
Poi rieseguire reverse start sul riferimento e su questa directory per
verificare il piano effettivo. Se viene richiesto Pro, l'utente deve decidere
e completare personalmente l'eventuale upgrade; nessun billing automatico.

Il tentativo di login ha aperto la pagina OAuth HeyGen ed è stato interrotto
per non lasciare il listener locale in attesa dopo la consegna dello stato.
